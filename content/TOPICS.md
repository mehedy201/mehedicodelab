## How to add an article
1. Create `content/articles/your-slug.md` (the file name becomes the URL).
2. Start with the front matter: `title`, `description` (150 to 160 characters), `date`, `category`, `tags`, and optional `updated` and `results`.
3. Write with `##` and `###` headings. Run `npm run build`. The article page, cover image, share image, sitemap and RSS update on their own.
